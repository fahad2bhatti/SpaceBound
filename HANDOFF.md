# SpaceBound: Beyond Earth - handoff notes (written 2026-11-12)

## What this is
A 3D browser space-shuttle simulator (Three.js) wrapped as an Android app with Capacitor.
Gameplay: walk the spaceport, buy/select ships, board, countdown + launch, fly to Earth orbit / Moon / planets,
land, explore on foot, return. Progress is saved in localStorage. No server, no auth, no API calls.
The first version was generated by Grok from a long spec prompt (ask Fahad for it if needed).

## Stack
Vite 8 + React 19 + Tailwind 4 + three (procedural models, no external assets), lucide-react,
Capacitor 8 (android, @capacitor/app). App id: com.fahadapps.spacebound. Web dir: dist.

## Code map
- src/game/engine.ts   - the `Spacebound` class: game loop, screens (menu/play/pause/garage/missions/solar/settings/credits),
                         phases (pad/cockpit/flight/surface...), flight physics, Solar chart, nav target + beacons,
                         `getSnap()` (state for React), `escape()` (public Esc logic), `projectTarget()` (destination marker).
- src/game/input.ts    - keyboard/mouse/touch state. Touch: `input.touch` {x,y,jump,run,rcsUp,rcsDown,pitchUp,pitchDown}.
                         In flight: touch.x<-0.25 = steer left, >0.25 = right; touch.y>0.3 = throttle up, <-0.3 = down.
- src/game/models.ts   - procedural ships/Earth/Moon/stars (`buildStars`).
- src/game/save.ts     - localStorage save.
- src/game/waypoint.ts - pure `placeWaypoint()` for the on-screen destination marker.
- src/components/spacebound/Game.tsx - all React UI: Menu, Panel, Cmd, Hud, Pause, Solar, Touch, Stick, TouchBtn, Waypoint.
  UI talks to the engine with `act((e) => e.something())`.
- src/styles.css       - Tailwind theme (--color-bg #07090D, primary #8ECFFF, accent #E8893A) + compact-menu CSS.
- android/             - Capacitor Android project (MainActivity.java patched for fullscreen).
- make_icons.mjs + assets/ - icon/splash source images (generated with sharp); `npx capacitor-assets generate --android`.

## Changes made so far (all via patch scripts, applied to sb-spa)
1. Flight steering fixed (left/right were inverted): engine.ts rotateY sign + bank sign.
2. Joystick rewritten with pointer capture; touch buttons enlarged (64px), joystick 144px.
3. Android: landscape lock (sensorLandscape in AndroidManifest), immersive fullscreen + keep-screen-on + notch support
   (MainActivity.java), hardware Back button (pause / resume / exit on menu) via @capacitor/app.
4. Top-centre buttons: `II` pause (calls engine.escape()) and MAP (pause + open Solar chart to choose a destination).
5. Destination marker in flight: diamond + name + distance, edge arrow when off-screen/behind (Waypoint in Game.tsx, rAF-driven).
6. Flight touch layout: D-pad (up/down = pitch, left/right = steer) replaces the joystick in flight;
   right side has E, C, THR+, THR-, RCS+, RCS-. On foot: joystick + E, C, JUMP, RUN.
7. Main menu compacted for phone landscape (narrow translucent panel, 2-column secondary buttons) so the 3D background shows.
8. Stars are round soft sprites instead of square points.
9. Icon + splash generated (make_icons.mjs) - verify on device, then commit.

## Build and run on the phone (Ubuntu laptop, Android phone with USB debugging)
cd /mnt/data/dev/sb-spa
npm run build && npx cap sync android
export ANDROID_HOME=$HOME/Android/Sdk; export PATH=$PATH:$ANDROID_HOME/platform-tools   # needed in every new terminal
npx cap run android          # or: npx cap open android -> Run in Android Studio
Do not uninstall the app casually: it wipes the localStorage save.

## Working conventions with the owner (Fahad)

## Known issues / untested
- `npx tsc --noEmit` shows old type errors (e.g. Input.override is private but used by the engine). Vite build ignores them.
- Changing the destination mid-flight (MAP button) was not tested against mission/landing rules.
- Phone performance (shadows, post-processing) not measured; default quality may need to be lower on phones.
- Other panels (Garage, Missions, Settings, Credits) are not compacted for phone landscape yet.
